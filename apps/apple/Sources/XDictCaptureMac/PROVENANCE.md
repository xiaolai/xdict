# XDictCaptureMac — migration manifest

Capture's macOS target, under XDict ADR-0014 decisions 5 to 7 and 10, plan-capture WI-2. Its files come from two
places: XiaolaiDict's `MacCapture` (`../xiaolaidict`, read at commit 044dac6), and XDict's own `XDictAnywhere`, from
which the selection reader moved down. One row per file: where it came from, the tests that moved with it (by their
names, now in `Tests/XDictCaptureMacTests/`) and the ADR behind it. "ADR-00nn" without a prefix is XiaolaiDict's; XDict's
are written "XDict ADR-00nn".

**Provenance check (2026-10-18, by reading).** Every XiaolaiDict origin file below and its tests were read in full while
porting. `git log 044dac6` names one author, the owner, over every path: 11 commits over the twelve paths read for
this target (`Sources/MacCapture/{AccessibilityAccess,AccessibilitySession,ScreenWordReader,ScreenWordSource,SelectionText,Permission}.swift`,
`Sources/Capture/ProcessResolver.swift`, `Tests/XiaolaiDictTests/AccessibilityBudgetTests.swift`,
`Tests/MacCaptureTests/{ScreenWordBoundsTests,AccessibilityAccessTests,SelectionTests}.swift`,
`Tests/CaptureTests/ProcessResolverTests.swift`), and 16 once `Sources/MacCapture/SelectionReader.swift` — the origin
of XDict's own reader, ported in plan-macos-v1 WI-8 — is counted with them (recounted 2026-10-18 after the verifier
counted 15 over a set it did not name); no file carries a licence
header, a copyright line or text from another project, and none of them is, or was translated from, third-party code.
XiaolaiDict has no licence file, so this is a recorded check, not a given (XDict ADR-0014 Context). The files moved from
`XDictAnywhere` are XDict's own, with their history in this repository.

**For WI-3 (the hover reader): read a hover's text only through `PointerWordSource.readUnlessRefused`.** It is one lane
job that checks the site (fail-closed: `unreadable` unless the walk to the application is complete and every web area on
it decided) and then reads, so a page cannot navigate between a check and a read. The source offers no separate host or
read call on purpose, and `PointerWordReader.read` and `.host` are internal (tests reach them
through `@testable import`), so `readUnlessRefused` is the only public way to read a hover's text. Third round of WI-2: eight more tests in `SiteExclusionTests` (a parent that cannot be read, a
frame with no address, the walk's limit, a cycle, the combined job twice, and random trees against a model of the rule).
