# The forms module's labelled cases, frozen before the module

`dev-docs/plan-phrase-recognition.md` WI-2, and the refutation's objections 5 and 6: the forms module may not be
measured on sentences generated by its own rules. This file is the labelled set, written and committed before the
module exists; `tests/forms_labelled.rs` runs it.

Each line: `surface | must include (comma-separated) | must not be the only candidates (empty)`. A missing `must
include` is a recall failure, printed by the test. `must not` is unused in v1 except in the two negative rows below.
